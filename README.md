# Jie Zhou — Academic Homepage

Personal academic website: https://niqz0301.github.io/

This website contains a research overview, publications, education, awards, academic service, and a downloadable CV.

## Publishing

GitHub Pages publishes the main branch, using the repository root directory.
The .nojekyll file keeps the HTML, CSS, JavaScript, and PDF files as static assets.

## Updating

- Edit index.html for biography and background information.
- Update papers.json and the embedded publication-data and static publication entries in index.html together.
- Replace Jie_Zhou_CV.pdf when the CV changes.
- Update sitemap.xml when the website content changes.
- Keep the Google verification tag in index.html to retain Search Console verification.
